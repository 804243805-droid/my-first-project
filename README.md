# MyFirstProject · 我的第一个网页作品

一个简洁、现代的个人作品展示页，使用原生 **HTML + CSS + JavaScript** 编写，无需任何构建工具或第三方依赖，双击即可在浏览器中运行。

适合作为前端入门练手项目，也适合当作后续作品集网站的起点。

## 预览

**在线访问：** https://804243805-droid.github.io/my-first-project/

**本地访问：** 直接用浏览器打开 `index.html`，或起一个本地服务器（更接近真实部署环境）：

```bash
# 任选一种，需在项目根目录执行
python -m http.server 8000
# 或
npx serve .
```

然后访问 http://localhost:8000

## 技术要点

| 技术 | 用途 |
| --- | --- |
| HTML5 语义化标签 | `header` / `nav` / `main` / `section` / `article` / `footer` |
| CSS 自定义属性 | 通过 `:root` 变量统一管理配色、阴影与字体栈 |
| CSS Grid & Flexbox | 主视觉、卡片网格、导航栏与 CTA 布局 |
| 媒体查询 | 适配桌面端、平板与手机屏幕 |
| IntersectionObserver | 判断当前所在板块并高亮对应导航项 |
| Open Graph 标签 | 分享到聊天工具 / 社交平台时展示卡片信息 |

## 页面板块

- **导航栏** — 品牌标识、锚点链接（含当前板块高亮）、行动按钮
- **主视觉（Hero）** — 标题、副标题、双按钮、数据统计、浏览器窗口示意卡片
- **关于项目** — 三张信息卡片：项目目标、适合人群、可扩展性
- **项目亮点** — 响应式布局 / 现代视觉设计 / 交互效果
- **联系我** — 邮件行动召唤
- **页脚** — 版权信息与仓库链接

## 无障碍与性能

这个项目刻意做了几件容易被忽略的事：

- **不依赖外部字体服务** — 不再请求 `fonts.googleapis.com`，改用系统字体栈。页面加载更快，在国内网络环境下也不会因为字体请求超时而卡住首屏。
- **锚点不会被导航栏遮住** — 用 `scroll-padding-top` 给吸顶导航预留空间，这是这类页面的常见毛病。
- **尊重「减少动态效果」** — 系统开启该偏好时，平滑滚动和所有过渡动画自动关闭。
- **键盘可用** — 提供「跳到主要内容」链接，并保留清晰的 `:focus-visible` 焦点轮廓。
- **渐进增强** — 禁用 JavaScript 后页面依然完整可用，平滑滚动与悬停效果全部由 CSS 实现。
- **屏幕阅读器友好** — 纯装饰的窗口示意卡片标记为 `aria-hidden`，当前板块用 `aria-current` 标注。

## 部署

本项目已开启 **GitHub Pages**，推送到 `main` 分支后会自动重新发布。

如需在自己的仓库中重新配置：进入 **Settings → Pages**，把 Source 设为 `Deploy from a branch`，分支选择 `main`、目录选择 `/ (root)`，保存即可。
